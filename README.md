# SimpleChatFilter

Minecraft (Paper 26.2対応) 向けのシンプルなチャットモデレーションプラグインです。
サーバー内の不適切な発言やスパムをシステム的に防ぎ、初見のプレイヤーでも安心して過ごせる環境を作るために開発しました。

## 主な機能
1. **NGワードブロック機能**
   - 設定された不適切な単語が含まれるチャットの送信を自動でキャンセルします。
2. **連投（スパム）防止機能**
   - プレイヤーごとの発言間隔を記録し、一定時間（デフォルト3秒）以内の連続投稿を制限します。

## 開発の背景
サーバーの温かく居心地の良い空気を守るため、人力のモデレーションだけでなく、システム面からもサポートできる仕組みが必要だと考え、プロトタイプとして作成しました。

## ディレクトリ構成
- `src/main/java/com/yourname/chatfilter/Main.java` : プラグインのメイン処理（イベントリスナー）
- `src/main/resources/plugin.yml` : プラグインの設定ファイル
